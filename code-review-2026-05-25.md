> Замечания по Go коду:

> `r.With(middleware.Timeout(5 * time.Second)).Post("/org-units", loaderProxy.ServeHTTP)`
>
> Пути к микросервисам (/workshops, /nomenclature...) должны быть в файле настроек

> **Auth-service**
>
> Убрать из названия service, просто auth, по аналогии с другими микросервисами. Поменять путь к нему в БФФ.

> Строка 79 (Role: "Executor",) - Роль возвращается константой, должна быть в БД
>
> Нужно чтобы Auth возвращал и сохранял роль пользователя для проброса в другие микросервисы. Там будет проверка доступа пользователя к тому или иному функционалу в зависимости от роли.
>
> **Migration**
>
> Стандартизировать названия таблиц
>
> `tech_card_content -> tech_card_items`
>
> `production_orders -> re_orders`
>
> В миграции должны быть только финальные CREATE table, CREATE INDEX (никаких ALTER TABLE, UPDATED, DELETE, ADD COLUMN не должно быть)
>
> **Mes-Sync**
>
> Kafka-admin - main: sendTest - в майне не должно быть тестовых запросов
>
> testdata папка, тесты комитить и заливать в git не нужно (gitignore)
>
> workshop_mappings.json - какой-то артефакт, в будущем убрать
>
> Папка models - внутри все типы разбиты по отдельным файлам, их можно запихать в один файл.go
